## 📖 О проекте

**Flintro** — мобильное приложение, которое помогает людям находить друзей и круг общения по интересам, а не только по фотографии или геолокации, как это устроено в большинстве аналогичных сервисов.

Идея проекта родилась из простого наблюдения: многим людям сложно социализироваться — у каждого свой характер, стиль общения и увлечения, и существующие приложения для знакомств редко учитывают это по-настоящему. Flintro делает ставку на **осмысленный подбор собеседников** и **простой, понятный интерфейс**, а также предусматривает защиту от спам-аккаунтов.

## 👥 Целевая аудитория

Приложение рассчитано на широкую аудиторию, но в первую очередь ориентировано на три группы пользователей, для каждой из которых предусмотрены свои сценарии взаимодействия:

- 🧑‍🎓 Подростки
- 🎓 Студенты
- 🧑‍💼 Люди среднего и старшего возраста

## ✨ Возможности

- 🔍 Поиск новых знакомств
- 🎯 Настройка интересов пользователя
- 💬 Взаимодействие с подобранными собеседниками
- ❓ Ответы на вопросы и просмотр вопросов других пользователей
- 🔗 Подключение аккаунтов социальных сетей для более точного анализа интересов и круга общения

## 🆚 Почему не аналоги

| Продукт | Ограничение |
|---|---|
| Badoo | подбор в основном по фото и близости геолокации |
| OkCupid | недоступен в России |
| Sapio | не работает на момент анализа |
| Splish | недоступен на момент анализа |

Flintro стремится закрыть эти пробелы за счёт более точного подбора и защиты от фейковых/спам-аккаунтов.

## 🚀 Запуск проекта

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Deomap/Flintro.git
   ```
2. Откройте папку проекта в **Android Studio**.
3. Дождитесь синхронизации Gradle.
4. Запустите приложение на эмуляторе или физическом устройстве с Android 5.1+.
